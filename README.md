# vidi-id

Documenti pubblici di identità (`did:web`) degli emittenti di attestati VIDI, pubblicati su
`https://vidi.formazionesicurezza.org` con GitHub Pages.

- `org/<id>/did.json` — documento DID di ogni ente (nome e chiavi pubbliche Ed25519)
- `did.json` — documento DID della piattaforma

Contiene solo dati pubblici: nessun dato personale, nessuna chiave privata.
I file sono generati dal repository principale.
